# 专题 9: 属相、婚配与关系判断

## Core Idea
属相用相冲、相合、三合、三会判断关系。相冲是性格不合（鼠胆小心缺安全感vs马冒进），三合三会是五行力量聚合。但作者强调『合也不一定好』，判断关系要结合性格与具体情境，预防大于治疗。

## Frameworks Introduced
- **相冲**: 生肖数相差6者相冲，距离最远、阴阳不平衡，多因性格不合。
  - 何时用：判断两人冲突根源
  - 做法：看属相性格差异，如子鼠午马的安全感vs冒进
- **三合三会**: 三合是五行力量变化过程（长生—帝旺—墓库），三会是三方聚一方之气。
  - 何时用：分析属相组合
  - 做法：寅午戌合火局、寅卯辰三会木局等
- **六合**: 十二生肖两两相配共六对，天道左旋地道右旋。
  - 何时用：看婚姻搭配
  - 做法：六合是大面上的好，但也要看怎么合
- **预防大于治疗**: 未婚前找个阴阳合和的最好，已婚就彼此包容。
  - 何时用：婚恋选择时
  - 做法：优先预防，已成形则经营而非强改

## Key Concepts
- **相冲**：鼠马、牛羊、虎猴、兔鸡、龙狗、蛇猪六组
- **三合**：寅午戌、申子辰、巳酉丑、亥卯未
- **三会**：寅卯辰木、巳午未火、申酉戌金、亥子丑水
- **六合**：子丑、寅亥、卯戌、辰酉、巳申、午未

## Mental Models
- Use 相冲 when 解释反复冲突——多因性格不合，需互相体谅
- Think of 三合 as 五行从长生到墓库的生命过程
- Use 预防大于治疗 when 问婚配——婚前选择优于婚后强改

## Anti-patterns
- **合就是好**：合还要看怎么合，找漂亮媳妇/有钱老公不一定就好
- **属相决定论**：相冲只是性格倾向，包容可化解

## Worked Example
作者详述六组相冲的性格逻辑：鼠（内心缺安全感、疑心重）vs马（敢冲不顾虑）；牛（内在倔强脆弱）vs羊（表面不灵、内心挑剔）；虎（霸道）vs猴（不服）；兔（心眼多未雨绸缪）vs鸡（记吃不记打）；龙（大开大合）vs狗（踏实保守）；蛇（冷静机智）vs猪（正直天真）。结论：相冲是性格不合，互相体谅是关键。

## Key Takeaways
1. 相冲本质是性格差异，理解对方才能减少冲突
2. 三合三会是五行力量的聚与变，非简单吉凶
3. 六合也要看具体条件，合不等于好
4. 婚配讲预防大于治疗，已婚者重在包容经营
