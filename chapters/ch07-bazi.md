# 专题 7: 八字：看性格、运势与格局

## Core Idea
八字（四柱）用天干地支反映先天格局。书中主打『看性格』『看运势』的简化用法：看是否得天运相助；并引出『有病方为贵』——有坎坷的八字才可能成富贵大格局，但前提是有药（努力+贵人+积德+外力）。

## Frameworks Introduced
- **八字看性格**: 通过日主与五行偏颇判断性格倾向。
  - 何时用：了解一个人时
  - 做法：看其八字五行分布与日主强弱
- **八字看运势**: 核心看『得不得势』——天运助则顺，天运不助则乏力。
  - 何时用：判断大运流年
  - 做法：看天运是否助力，结合具体行业信息
- **有病方为贵**: 有坎坷的八字才可能成大格局；完美意味着安稳，需经打磨才能大成。
  - 何时用：遇到命局有缺憾时
  - 做法：不要急于否定，看是否有『药』来补救
- **药=内外合力**: 个人努力、贵人提携、积德行善、祖先保佑、外力助缘，抓住一切机会。
  - 何时用：想改命时
  - 做法：内因外因一起抓，不把内外对立

## Key Concepts
- **四柱八字**：年月日时四柱，共八个字，反映先天格局
- **得势**：天运助我则有力，不助则乏力
- **有病方为贵**：命理术语，有缺陷经打磨反成大格局
- **虚岁**：命理用虚岁，加上胚胎孕育期，先天后半各半

## Mental Models
- Use 有病方为贵 when 看到命局坎坷——关键看有没有『药』接住
- Think of 运势 as 得不得天运之助——助则顺、不助则蓄力
- Use 内外合力 when 想改变命运——靠自己是必要但非唯一条件

## Anti-patterns
- **只靠自己**：佛陀成佛也拜师、道家炼丹需丹方草药，没人靠自己单独成功
- **把苦难等同于成就**：经历磨难的人很多，成就大事的少；关键在苦难中能否动心忍性

## Worked Example
赌博桌上道长开示：把把输反而该谢祖师爷——没尝甜头就不会倾家荡产。进而讲『有病方为贵』：有病的八字才可能富贵，但必须有药。药是个人努力、贵人提携、积德行善、祖先保佑、外力助缘。有人问『修行靠自己就行吧』，道长笑：你想得美，佛陀成佛前也拜师。

## Key Takeaways
1. 八字看运势主要看得不得天运之助
2. 有病方为贵的前提是有药——坎坷须配上主观努力与外部助缘
3. 把个人努力与外在条件对立起来是误区
4. 福祸相依，眼前的『输』可能是避免了更大的坑
