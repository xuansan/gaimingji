# 专题 4: 六爻：装卦、六亲与用神

## Core Idea
六爻是全书示范最多的预测术。摇六次硬币成卦，每爻装六亲六神；六亲按五行生克定义，代表万事万物。看考试看父母爻，看自己看世爻，看外在看应爻。

## Frameworks Introduced
- **装六亲**: 生我者父母、我生者子孙、克我者官鬼、我克者妻财、同我者兄弟。
  - 何时用：拿到一卦要定用神时
  - 做法：先定卦宫五行，再按生克给六爻装六亲
- **六亲的类象**: 父母=过去/学业/成绩，兄弟=现在/朋友，子孙=未来/福气，官鬼=事业/压力，妻财=财富/妻子。
  - 何时用：判断某件事看哪个爻
  - 做法：按类象选准用神，如考试看父母爻
- **世应**: 世爻代表自己，应爻代表外在/对方。
  - 何时用：分析主客关系
  - 做法：看世应五行生克与旺衰，判断自身与外部环境
- **旺衰**: 用神强弱要结合月建、季节五行判断，且要考虑应期时运。
  - 何时用：判断用神有力无力
  - 做法：看起卦月+应期时的五行生克

## Key Concepts
- **六亲**：父母/兄弟/子孙/官鬼/妻财，按与卦的五行关系定义
- **六神**：青龙木、白虎金、朱雀火、玄武水、勾陈腾蛇土
- **世爻**：代表求测人自己
- **应爻**：代表外在环境或对方
- **用神**：所测之事对应的爻，如考试为父母爻、求财为妻财爻

## Mental Models
- Use 六亲类象 when 选用神——父母是我之来处（学业），子孙是我之未来
- Think of 世应 as 主客——世为自己应为外在，看二者生克
- Use 旺衰判断 when 世爻极弱——先想弱极必反，别急着断死

## Anti-patterns
- **用错用神**：看考试却盯妻财爻，方向一开始就错
- **忽略应期**：只看起卦时不看结果发生时的时运

## Worked Example
李雪考研卦：父母持世五行为火，代表成绩的父母爻与代表自己的世爻合一。丑月（冬、水旺）火极弱，常规断必败；老徐反断，因3月春木生火、时运助她。这个案例完整演示了装六亲、定用神、看旺衰、查应期、用反断的全流程。

## Key Takeaways
1. 六亲是类象系统，先定卦宫五行再装六亲
2. 考试看父母爻、求财看妻财爻、看自己看世爻
3. 旺衰要同时看起卦月与应期时运
4. 父母持世=成绩与自己合一，是重要结构信号
