# 专题 1: 阴阳世界观与全书总纲

## Core Idea
全书主线是风水，核心是阴阳五行的推理思维；作者以「用科学解释玄学」为立场，主张大道至简、无非阴阳，学易不是为了认命而是为了改变、为了更好地顺势而为。

## Frameworks Introduced
- **大道至简，无非阴阳**: 万事万物皆分阴阳，阴阳是关系不是标签；判断吉凶前先看阴阳是否平衡。
  - 何时用：面对任何现象先分辨阴阳两面，再看是否失衡
  - 做法：把事物按阴阳归类，观察动态平衡，避免绝对化
- **用科学解释玄学**: 把命理概念翻译成可理解的经验语言（风水=温度湿度），反对盲信也反对一概否定。
  - 何时用：向怀疑者解释玄学概念时
  - 做法：找到概念对应的现实机制，用对方能接受的语言表述
- **先天为体，后天为用**: 先天是不可变的根本（天道），后天是可选择的应用（人道）；学易重点放在后天。
  - 何时用：讨论命与运的关系时
  - 做法：承认起手牌（先天）已定，把精力放在打法（后天）的选择上
- **阴阳是关系不是标签**: 阴阳随比较对象而变，心脏对六腑为阴、对肾脏为阳。
  - 何时用：判断某物阴阳属性时
  - 做法：先确定比较对象，再下结论

## Key Concepts
- **阴阳**：相互对立又依存的两面，如静与动、内与外，是关系而非固定属性
- **道**：宇宙的核心规律；道生德养，德是道的外显与能量化
- **风水**：风（温度）与水（湿度），一切生命体的生存条件
- **后天八卦**：应用之学，四柱、奇门、风水皆以此为主
- **先天八卦**：体之学，取其数与后天之象配合（象数疗法）
- **顺势而为**：在承认约束的前提下选择最优打法，而非硬抗或认命

## Mental Models
- Use 阴阳平衡 when 判断健康、财运或关系——先看是否偏枯，再谈吉凶
- Think of 命 as 起手牌、运 as 打法——牌已定，输赢看人怎么打
- Use 先天为体后天为用 when 有人问『能不能改命』——先天不改，后天大有可为
- Think of 玄学 as 待验证的经验科学——不盲信、不轻蔑

## Anti-patterns
- **把阴阳当固定标签**：『心脏属阴』脱离比较对象就失去意义，阴阳是活的相对关系
- **以玄学之名拒绝验证**：作者明确反对不修仙不玄幻、要经得起验证

## Worked Example
作者借老道儿之口，用『医学是否科学』发问：肿瘤切除后会不会复发医生不能确定，风水=温度湿度反而是生命必要条件。结论不是玄学万能，而是不要用二元对立的『科学/迷信』标签封死认知。

## Key Takeaways
1. 万事分阴阳，但阴阳是关系不是标签，切忌绝对化
2. 学易为改变而非认命，重点永远在可选择的后天
3. 先教使用再究原理（象数疗法先教用后天八卦），实用主义优先
4. 用对方能听懂的语言（科学语汇）解释传统概念，减少对立
