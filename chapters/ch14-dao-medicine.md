# 专题 14: 道医、偏方与身心调理

## Core Idea
书中大量医案：祝由术（便秘符、小儿退烧）、麦粒肿、悬针纹、鼻炎、高血压、近视、失眠、口腔溃疡、妇科、癌症前兆等。核心立场：预防大于治疗；身心相连（恐伤肾、情绪致病）；偏方是辅助，严重问题须就医。

## Frameworks Introduced
- **预防大于治疗**: 在病成形前调理，胜于病后猛药。
  - 何时用：面对健康问题时
  - 做法：优先调整生活方式与早期信号
- **身心相连**: 恐伤肾、怒伤肝、念头影响基因表达，情绪与器官对应。
  - 何时用：找疾病根源时
  - 做法：同时看情绪、心念与生活习惯
- **祝由术**: 以符咒、仪式辅助治病（便秘符、小儿退烧等）。
  - 何时用：理解传统疗法时
  - 做法：视为辅助手段与心理暗示，不替代医疗
- **偏方辅助**: 书中有大量食疗/外用偏方（香蕉、绿豆黑豆等），但强调严重疾病须正规治疗。
  - 何时用：日常小恙
  - 做法：在安全前提下尝试，重症立即就医

## Key Concepts
- **祝由术**：古法以符咒祝祷治病
- **情志致病**：恐伤肾、怒伤肝等情绪与脏腑对应
- **基因表达**：书中引用念头影响基因表达的科学说法
- **辟谷**：篇外专题，断食调理法

## Mental Models
- Use 预防大于治疗 when 身体出现小信号——早调整胜过晚治疗
- Think of 情绪 as 病因之一——问病先问心
- Use 偏方 as 辅助——重症必须就医，不迷信偏方

## Anti-patterns
- **讳疾忌医**：偏方是辅助，癌症等问题必须正规治疗
- **情绪无关健康**：恐伤肾、怒伤肝，心念影响身心

## Worked Example
作者讲光煞致病：潜意识恐惧伤肾、肾主骨，久成风湿骨病；心肾相交又影响心血管与神经。讲麦粒肿、悬针纹、鼻炎、高血压、近视等，皆从阴阳五行与生活习惯入手。对癌症前兆一节尤其强调早发现。整体基调：道医调身调心，但不否定现代医学。

## Key Takeaways
1. 预防大于治疗，重视早期信号
2. 情绪与心念是重要病因，身心一体
3. 祝由与偏方属辅助，重症必须就医
4. 用科学语言解释传统医理，减少玄虚感
