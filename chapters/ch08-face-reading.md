# 专题 8: 面相与手相：五官、三停、掌纹

## Core Idea
面相手相是全书高频的『术』。核心方法：三停对应父母/自己/子孙与上中下年龄段；看五官、手相要阴阳辩证，吉凶不固定；相由心生，相貌与风水、心性互相影响。

## Frameworks Introduced
- **三停对应**: 上庭=父母祖先/青少年，中庭=兄弟配偶/中年，下庭=子孙/晚年。
  - 何时用：看面相分区
  - 做法：先定三停，再对应人生阶段与亲属关系
- **阴阳辩证看相**: 硬为阳骨为阳、软为阴肉为阴；肉为财，骨多肉少为竹节手主漏财，但阳性强善思考。
  - 何时用：判断某个相征好坏时
  - 做法： avoid 绝对化，看是否阴阳平衡、看具体比较对象
- **相由心生**: 额头饱满祖荫好、眉间距宽心大、五官随心境与运势变化。
  - 何时用：理解相貌变化时
  - 做法：把相看成动态结果，不是宿命标签
- **五行人分类**: 五行人之木等人分类法，按形态气质归五行。
  - 何时用：快速判断人的气质
  - 做法：观察体貌气质归入五行，再推性格倾向

## Key Concepts
- **三停**：面上庭/中庭/下庭，对应不同人生阶段与六亲
- **悬针纹**：面相术语，书中专章讨论
- **竹节手**：骨多肉少、关节粗的手型，传统主漏财但阳性强
- **肉为财**：相学欧姆，肉的多少需相对骨架判断，瘦到露骨才不利财
- **眉头阔大快活**：眉间距宽者心大，少生气易长寿，但感情上也可能来者不拒

## Mental Models
- Use 三停 when 从面相切入人生阶段——上庭看早年祖荫
- Think of 相 as 动态——相由心生，心转相可转
- Use 阴阳辩证 when 判断吉凶——竹节手既漏财又善察，福祸相依

## Anti-patterns
- **相征绝对化**：肉为财要相对骨架，一味求胖反而可能代谢问题
- **以貌取人下结论**：相只是参考维度，需结合其他信息综合判断

## Worked Example
讲大拇指：头尖思维敏捷、圆厚不懂变通、外张外向、紧贴食指肾气胆小。讲竹节手：传统说不吉主漏财，但阳性强、善观察社交。作者反复强调『阴阳是关系不是标签』——心脏对六腑为阴、对肾为阳，就像杜乐相对海哥矮、相对琪儿高。

## Key Takeaways
1. 面相看三停对应人生阶段与六亲
2. 手相、五官判断要阴阳辩证，吉凶不固定
3. 相由心生，相是动态结果不是宿命
4. 任何单一相征都要放回整体平衡中解读
