# 专题 12: 姓名学与符号预测

## Core Idea
姓名学看字形字义的阴阳五行：如『梅』冬花冷艳孤傲情困、『玲』多晚婚、女用男字主婚姻缺憾；名字的笔画数可用于起卦（加姓笔画）。头像、手机号、锁屏密码等符号也被纳入预测体系。

## Frameworks Introduced
- **字形字义断**: 拆解汉字的偏旁、含义、季节意象推断性格与运势。
  - 何时用：分析名字时
  - 做法：看字形阴阳、字义季节与意象
- **姓名起卦**: 时间起卦时加姓名笔画数，区分不同人同时起卦。
  - 何时用：多人同时占卦
  - 做法：年+月+日+姓笔画，用于区分信息频率
- **符号预测**: 头像、手机号、锁屏密码等个人符号可反映或影响运势。
  - 何时用：看一个人的外在符号
  - 做法：把常用符号纳入整体判断，但不迷信单一符号

## Key Concepts
- **姓名学**：以字形字义笔画论命的方术
- **四桃花**：子卯午酉，位置居中、本气纯正，又称四正位
- **招桃花**：姓名或符号中引发感情姻缘的因素

## Mental Models
- Use 姓名笔画 when 多人同时起卦需区分——加姓笔画数
- Think of 字形 as 意象——梅之孤傲、玲之晚婚，看字义季节
- Use 符号预测 as 辅助维度——头像手机号的风格反映心态

## Anti-patterns
- **名字决定论**：名字只是参考维度之一，不可单凭名字断人
- **缺什么补什么**：取名看喜用神，不是简单补五行缺项

## Worked Example
作者讲姓名学：『梅』冬季开、冷艳孤傲情困婚姻多不顺；『玲』多晚婚；女用男字（凤）主婚姻缺憾，男用女字主感情纠葛；三撇（彡）伤人伤财伤感情（珍）。并强调取名第一步是找准喜用神，八字所缺不一定就是喜用。

## Key Takeaways
1. 姓名学拆字形字义与季节意象
2. 多人同时起卦可加姓名笔画数区分
3. 取名看喜用神，不是缺啥补啥
4. 头像、手机号等符号可作辅助参考但不迷信
