# 专题 10: 风水：煞、能量与居家调整

## Core Idea
风水是全书主线。作者用科学语言解释：风水=温度湿度；镜子反光成光煞（潜意识恐惧伤肾）；煞气可为财也可为害；调整风水要匹配个人命理，且只是外力助缘。重点章节含境煞、风煞、五鬼位、厕所、炉灶坐向、补角、财务通道。

## Frameworks Introduced
- **光煞原理**: 大面积镜子/反光饰条形成光煞，晃影引发潜意识恐惧，恐伤肾、影响心神与骨骼。
  - 何时用：居家布置时
  - 做法：避免大面积镜子，或用不透光布帘遮住
- **煞气为财**: 煞气不全然是坏事，某些位置煞气反而催财；关键是匹配与化解。
  - 何时用：看到煞位时
  - 做法：判断是催财还是为害，不一律消除
- **命理匹配**: 什么样的命理对应什么样的风水，房子要与主人匹配，调整时会有人觉得『怪』。
  - 何时用：调风水前
  - 做法：先确认是否与主人命理匹配，不强求统一标准
- **风水是外因**: 业力是内因、风水是外因；外力只是助缘，离不开自身努力。
  - 何时用：期待改运时
  - 做法：把风水调整与修心、努力结合

## Key Concepts
- **光煞**：反光物体造成的光污染与心理暗示
- **境煞**：环境形煞，专章示范过镜子问题
- **风煞**：风的流向与煞气，书中专章
- **五鬼位**：风水方位概念，书中讲双五鬼位
- **财务通道**：风水上影响财运的格局，居家与论命都涉及
- **补角**：户型缺角时的补救方法

## Mental Models
- Use 光煞原理 when 家里有人莫名失眠惊恐——先查大面积镜子反光
- Think of 风水 as 外因助缘——内因（心性/努力）才是根本
- Use 命理匹配 when 调风水无效——可能这个房子与主人不匹配

## Anti-patterns
- **见煞就破**：煞气可能为财，需判断性质而非一味化解
- **风水决定论**：业力是内因、风水是外因，外力不能替代努力

## Worked Example
蔡总家客厅一整面镜子+亮面饰条，作者指出：反光形成光煞，晃影的瞬间恐惧即使没被大脑意识到也已造成伤害；恐伤肾、肾主骨，久而成风湿骨病；心肾相交又影响心血管与神经。建议拆镜或用米色布帘遮。作者拒收厚红包只取100作彩头，说等验证有效再还谢礼——无功不受禄，也是留情面。

## Key Takeaways
1. 镜子反光成光煞，恐伤肾并影响心神骨骼
2. 煞气不全然有害，需辨别催财还是为害
3. 风水要与主人命理匹配，调整时被嫌『怪』是正常的
4. 调风水只收彩头、见效再谢，是职业伦理也是经营智慧
