# 专题 17: 内求与外求：外力只是助缘

## Core Idea
全书反复出现的主线：内因（心性、努力、业力）是根本，外因（风水、法事、符咒、贵人）是助缘。『有病方为贵』强调苦难中奋发图强；『外力是感冒药』强调不可依赖；『神仙的能力也有限』强调自修才是根本。

## Frameworks Introduced
- **内外合力**: 个人努力、贵人提携、积德行善、祖先保佑、外力助缘，抓住一切机会；没有谁靠自己单独成功。
  - 何时用：想改变处境
  - 做法：内因外因一起抓，不把二者对立
- **外力不可依赖**: 借助外力好用易生依赖，阳不可被阴控制；外力如感冒药，能不吃就不吃。
  - 何时用：是否求助外力
  - 做法：能靠自己就靠自己，外力仅辅助
- **自修根本**: 神仙能力有限，世界靠每个人不生恨、不招魔；修之身、修之家、修之乡、修之国、修之天下。
  - 何时用：面对无法控制的外部环境
  - 做法：回到修好自己与身边人

## Key Concepts
- **内因**：心性、努力、业力，是根本
- **外因**：风水、法事、贵人等，是助缘
- **正气**：内在生命能量，正气足外邪不侵
- **道德经修之身**：由修身到修天下的递进，强调自我修行是起点

## Mental Models
- Use 内外合力 when 想改命——抓一切机会，内外都要
- Think of 外力 as 感冒药——辅助可以，依赖不行
- Use 自修根本 when 环境不可控——修己、修家是起点

## Anti-patterns
- **把内外对立**：靠自己是必要非唯一，外在条件也必要
- **依赖外力失自主**：阳被阴控制是危险的，外力用久生依赖

## Worked Example
道长说：有病方为贵，但病得有药——个人努力、贵人提携、积德行善、祖先保佑、外力助缘。有人问『修行靠自己就行吧』，答：佛陀成佛前也拜师。吉月姐姐说：神仙能力有限，贪嗔召唤的魔管不过来，唯一能依靠的是自己不生恨、正心正念，并引导身边人。智策师父：外力借助归借助，但不能把自己丢了，阳不能被阴控制。

## Key Takeaways
1. 改变命运要内外合力，内外不可对立
2. 外力只是助缘，依赖会削弱自身正气与自主
3. 自修是根本，修好自己再修家、修天下
4. 不生贪嗔恨，既修心念也修言行
