# 专题 15: 修行、功法与能量

## Core Idea
修行本质是『修日常行为』，先踏实工作养家再谈修行。书中功法：剑指站桩功、采日光功、洗心养神功、能量引导术、养心补肾手印、百脉通、六字诀、升阳跳、回春功、五行能量净化法、睡子午觉、念经念咒（唵阿吽）。外力是感冒药，能不吃就不吃。

## Frameworks Introduced
- **修行即修日常**: 修行不是打坐念佛的避世，而是踏实工作、敬养父母、抚育子女，生活就是道场。
  - 何时用：日常如何修行
  - 做法：把锅碗瓢盆、人际关系当作修行
- **外力如感冒药**: 法事、外力保健是辅助，依赖会降低自身免疫力（正气）。
  - 何时用：是否借助外力
  - 做法：能靠自己抗就靠自己，外力仅辅助
- **念咒原理**: 唵（头、振发精神）、阿（口、清理脏腑）、吽（心、开通脉结），接近梵音更好，发心更重要。
  - 何时用：念经念咒时
  - 做法：不必强求发音标准，重在不间断与发心
- **功法养生**: 站桩、采日光、手印、六字诀等，通过动作与呼吸调养身心。
  - 何时用：日常养生
  - 做法：选适合自己的功法坚持练

## Key Concepts
- **正气**：自身的生命能量与免疫力，外邪不侵的根本
- **外力助缘**：法事、符咒、风水等外部辅助，不可依赖
- **唵阿吽**：三个宇宙根本发音，对应头、口、心
- **子午觉**：睡子时午时以养阴阳的作息法

## Mental Models
- Use 修行即修日常 when 问『怎么修行』——先做好工作与家庭
- Think of 外力 as 感冒药——能不吃就不吃，依赖反伤正气
- Use 发心重于形式 when 念咒——梵音不准也没关系

## Anti-patterns
- **避世修行**：修行不离生活，父母孩子照顾不好谈何修行
- **依赖外力**：依赖鬼神外力会失去自主，阳不可被阴控制

## Worked Example
无优禅师开示：修行很简单，修的是日常行为；真正在家修行者先要踏实工作、敬养父母、抚育子女，家庭安稳才是红尘修行。生活是锅碗瓢盆交响曲，和谐不了离婚也很好，又获得一次选择机会。讲念经：声音有形状有力量，超声波可碎结石；唵阿吽分别作用于头口心，发心比发音标准更重要。

## Key Takeaways
1. 修行就是修日常行为，生活即道场
2. 先活着、先养家，再谈修行
3. 外力是感冒药，能不吃就不吃，靠自己提升正气才是正途
4. 念咒发心重于形式，唵阿吽对应头口心
