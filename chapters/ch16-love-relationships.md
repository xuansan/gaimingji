# 专题 16: 婚恋、桃花与感情判断

## Core Idea
感情问题在书中既是术（断桃花、婚配、头像影响）也是道（『爱的解读』『无条件的爱』『世界在我心里』）。作者反复强调向内求：心安神才定，外求缘分不如修好自己；桃花既可招也可斩，关键在心念与行为。

## Frameworks Introduced
- **婚配判断**: 用属相、面相、八字综合看两人是否合，相冲即性格不合需包容。
  - 何时用：判断感情适配
  - 做法：多维度综合，不只看单一指标
- **桃花与斩桃花**: 桃花指异性缘，烂桃花可通过风水/心念调整化解。
  - 何时用：遇到感情困扰
  - 做法：先分清是正缘还是烂桃花，再决定招或斩
- **心安神定**: 把注意力放在自己身上，修好自己，缘分自然来。
  - 何时用：感情焦虑时
  - 做法：向内求，减少对外在确认的依赖
- **无条件的爱**: 真爱是安静相处也幸福，不是占有与控制。
  - 何时用：理解亲密关系
  - 做法：从『索取』转向『成全』

## Key Concepts
- **桃花**：异性缘，四桃花为子卯午酉
- **烂桃花**：带来困扰的感情关系，可化解
- **心安**：心神安定，是吸引与判断的基础
- **正心正念**：不起贪嗔恨，是感情与修行的共同根基

## Mental Models
- Use 婚配综合判断 when 看两人关系——属相面相八字要合看
- Think of 桃花 as 缘分信号——正缘烂桃花要分辨
- Use 心安神定 when 感情焦虑——修己胜过外求

## Anti-patterns
- **执着于控制对方**：爱是成全不是占有，执着生痛苦
- **外求缘分不修己**：心安神才定，修好自己是根本

## Worked Example
多篇外讲『爱的解读』『无条件的爱』『世界在我心里』『躺平和接纳』。核心观点：合拍玩闹不一定是爱情，安静相处也幸福才是真爱；把注意力放在自己身上、修好自己，比追逐外在关系更重要。属相相冲本质是性格不合，包容可解。

## Key Takeaways
1. 感情判断要综合属相、面相、八字，不执单一指标
2. 桃花有正烂之分，化解关键在心念与行为
3. 心安神定，向内求比外求缘分更可靠
4. 真爱是无条件的成全，不是占有与控制
