# 专题 11: 择吉、九运与五行穿衣

## Core Idea
择吉有公式可算（红煞日算法等），三元九运用于判断时代运势（如抑郁/虚假的运势），五行穿衣法按五行生克助运，且有进阶版。作者强调择日是术，仍要结合具体情况。

## Frameworks Introduced
- **择吉公式**: 用固定公式推算吉日，红煞日等有专门算法。
  - 何时用：需要选日子时
  - 做法：按公式推算，结合事项性质
- **三元九运**: 把时间划为三元九运，用于判断大时代特征与个人运势背景。
  - 何时用：分析时代级趋势
  - 做法：结合九运特征理解群体现象
- **五行穿衣**: 按五行生克选衣物颜色助运，有基础版与进阶版。
  - 何时用：日常助运
  - 做法：根据自身喜用与场合选颜色

## Key Concepts
- **三元九运**：时间周期划分，用于运势判断
- **红煞日**：择日中的凶日，有专门算法
- **五行穿衣**：以颜色配五行助运的方法

## Mental Models
- Use 择吉公式 when 办重要事项需选日子——公式是基础，仍需结合具体事
- Think of 九运 as 时代背景板——个人运势放在时代大势中看
- Use 五行穿衣 as 轻量助运手段——配合喜用神选色

## Anti-patterns
- **择日万能论**：择吉只是术，需结合命理与具体情境
- **穿衣改命**：穿衣是助缘，不能替代修心与努力

## Worked Example
择吉公式与红煞日算法被列为专门的『术』章节，五行穿衣法从基础讲到进阶版。三元九运被用于解释『抑郁/虚假』等时代性现象。作者一贯的立场是：术是工具，用术而不迷术。

## Key Takeaways
1. 择吉有公式，红煞日等有专门算法
2. 三元九运提供时代级运势背景
3. 五行穿衣是按五行生克助运的轻量方法
4. 所有择日术都要结合具体人和事，不当万能钥匙
