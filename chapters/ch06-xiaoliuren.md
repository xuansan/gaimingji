# 专题 6: 小六壬（掐指神通术）

## Core Idea
小六壬又称诸葛马前课，是诸葛亮从奇门遁甲简化的快速占法。六神定吉凶，掐指顺数月日时即可得结果，是全书示范的入门级术法。

## Frameworks Introduced
- **掐指起卦**: 大安起食指根，按大安—留连—速喜—赤口—小吉—空亡顺时针数月、日、时辰。
  - 何时用：需快速占问时
  - 做法：在手指六位上依次数农历月、日、时辰
- **六神断吉凶**: 大安=静吉、留连=拖延纠缠、速喜=快而喜、赤口=口舌凶险、小吉=回归好运、空亡=无结果忧虑。
  - 何时用：得到卦位后
  - 做法：按六神含义直接解读事情性质与趋势

## Key Concepts
- **小六壬**：诸葛马前课，掐指即算的简化占术
- **六神**：大安、留连、速喜、赤口、小吉、空亡
- **时辰**：子丑寅卯等十二时辰，用于掐指最后一数

## Mental Models
- Use 小六壬 when 需要极快速的初步判断——掐指即得
- Think of 六神 as 六种态势标签——静、滞、速、凶、归、空

## Anti-patterns
- **不满意就换时间重测**：作者测毕业得赤口率不满意，老道儿说改测变吉才是真不准
- **机械迷信单一结果**：六神给的是态势，仍要结合具体情境

## Worked Example
作者用掐指测能否顺利拿毕业证，得赤口（主口舌是非）。他觉得不合逻辑想重测，老道儿说：为什么此时此刻你想测此事？这是天意；若不满意而等两小时重测变成小吉，那才是真的不准。随后用塞翁失马（塞翁是『善术者』）铺垫祸福相依的道理。

## Key Takeaways
1. 小六壬掐指数月日时，六神直接断吉凶
2. 起卦的时机本身有意义，不要挑时间重测
3. 凶兆不一定是坏事，塞翁失马焉知非福
4. 入门术法重在建立『时机+态势』的直觉
