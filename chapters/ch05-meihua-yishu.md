# 专题 5: 梅花易数与起卦的心法

## Core Idea
梅花易数极灵活：时间、报数、测字、方位、声音皆可起卦，万法同宗，找自己顺手的方法即可。核心是『心动发问，机兆已起』——起卦那一刻的信息已包含答案；断卦用心神感应，刻意干预就不准。

## Frameworks Introduced
- **多法起卦**: 年+月+日除8得上卦，加时除8得下卦，加时除6得动爻；亦可报数、测字、方位、声音起卦。
  - 何时用：需要起卦时
  - 做法：任选一种顺手的方法，保持专注单一
- **心动机兆**: 人动念发问的那一刻，信息场已定，时间起卦就包含对应信息。
  - 何时用：理解起卦原理时
  - 做法：把起卦时刻视为信息快照，不要事后刻意重测
- **初筮告，再三渎**: 第一次诚心占卜有启示，反复乱占则不再回应。
  - 何时用：想反复确认结果时
  - 做法：只起一次卦，接受第一次的结果
- **心神感应**: 断卦靠感应，不动脑子干预结果，即无为而治。
  - 何时用：解卦时
  - 做法：放松专注，不把主观愿望塞进解读

## Key Concepts
- **梅花易数**：邵雍所创、以灵活起卦著称的象数易学
- **外应**：起卦时外界的声、物、事等征兆，可加入判断
- **动爻**：卦中变化的爻，是事情的关键变量
- **初筮告再三渎**：《易经》占卜原则，强调首次占卜的严肃性

## Mental Models
- Use 心动机兆 when 解释为何起卦时机重要——那一刻信息已定
- Think of 起卦方法 as 工具——万法同宗，顺手即可，不必执着某一种
- Use 初筮告 when 有人想反复占同一件事——第一次的结果才可信

## Anti-patterns
- **对结果不满意就重测**：刻意等两小时再测变吉，老道儿说那才是真的不准
- **刻意用脑子干预解读**：断卦用心神感应，刻意就不准

## Worked Example
老爷爷问：同一时间很多人起卦结果一样吗？大师兄答：人心动发问机兆已起，时间里含对应信息；不同人同时测可加姓、加数、加外应。又问同一事不同时间测会不会不同？答：初筮告、再三渎，反复乱占就不准了。这段文字把梅花易数的『时机观』和『诚心观』讲得很透。

## Key Takeaways
1. 起卦方式灵活，万法同宗，选顺手的即可
2. 起卦那一刻的信息场已定，不要事后重测
3. 第一次诚心占卜的结果才可信，反复占反而不准
4. 断卦用心神感应，避免主观愿望污染解读
