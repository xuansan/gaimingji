# 专题 19: 心理学的挪用与算命心理学批判

## Core Idea
这是全书最清醒的部分：作者一面借心理学（光环效应、投射效应、虚假同感偏差、凤凰效应）解释现象，一面严厉戳穿『算命心理学』——问婚姻断婚姻不顺、问事业断事业不顺，『谁算谁准』，因为离婚率近半，闭眼断都能中。骗子用《英耀篇》的揣摩套路。

## Frameworks Introduced
- **算命心理学**: 问什么断什么『不顺』几乎必中：身体、招小人、婚姻、破财都是高概率事件。
  - 何时用：遇到算命大师
  - 做法：先想这是不是巴纳姆式的模糊命中
- **光环效应**: 以偏概全，一个亮点掩盖其他特质（反面：一个污点否定整体）。
  - 何时用：评价人或事
  - 做法：警惕第一印象的晕轮污染
- **投射效应/虚假同感偏差**: 把自己的想法投射到别人身上，以为别人和自己一样。
  - 何时用：理解人际冲突
  - 做法：意识到『我觉得』不等于『对方觉得』
- **巴纳姆式命中**: 用对大多数人适用的模糊描述让人觉得『算得真准』。
  - 何时用：识别话术
  - 做法：把描述换成具体可验证的细节再判断

## Key Concepts
- **算命心理学**：利用高概率模糊陈述制造『准』的错觉
- **英耀篇**：江湖术士揣摩人心的不传之秘，用于骗术
- **光环效应**：以点带面的认知偏差
- **投射效应**：将自己的念头归于他人
- **四正位/桃花**：子卯午酉，本书用于属相与感情判断

## Mental Models
- Use 算命心理学批判 when 遇到『大师』——问婚姻断不顺，谁算谁准
- Think of 光环效应 when 一好百好或一坏百坏——警惕晕轮
- Use 投射效应 when 冲突——你觉得的不等于对方觉得的

## Anti-patterns
- **迷信大师的『准』**：问什么断什么不顺，离婚率近半，闭眼断都能中
- **觉得自己总是对的**：投射效应让人把自己的想法当成别人的想法

## Worked Example
第226章『婚姻不顺，谁算谁准』：作者拆解——人吃五谷杂粮哪有不生病；意见不一致就怀疑招小人；离婚率近半、没离的也在凑合，所以断『婚姻不顺』能一网打尽。第92章：问婚姻断婚姻不顺、问事业断事业不顺，『只要不是来捣乱的都会准；来捣乱的也不准——是你心不诚』。作者推荐读《英耀篇》『防骗』。

## Key Takeaways
1. 算命『准』常是高概率模糊命中，不是真本事
2. 问什么断什么不顺是江湖套路，要警惕
3. 光环效应、投射效应是理解人际判断的重要偏差
4. 作者主张用心理学防骗，而非迷信权威
