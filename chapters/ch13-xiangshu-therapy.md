# 专题 13: 八卦象数疗法

## Core Idea
象数疗法是念特定数字组合治病的方法：取先天八卦的数、后天八卦的象，念数字时以头、心、胃三处是否有不适感来校验是否适合自己；念着不舒服就换一组数。作者强调先教使用再究原理的实用主义。

## Frameworks Introduced
- **先天取数后天取象**: 象数八卦疗法取先天八卦的数（乾1兑2离3…），配合后天八卦的象使用。
  - 何时用：选象数配方时
  - 做法：用先天数、后天象的框架理解数字组合
- **头心胃校验**: 念某组数字若头、心、胃不舒服，说明不适合，需换一组。
  - 何时用：念方前self-check
  - 做法：留意头心胃三处的感受作为适配信号
- **先教使用后究原理**: 像学手机先学打电话而非先学电磁理论，先用起来再回头研究原理。
  - 何时用：教别人复杂术法时
  - 做法：先给可操作的用法，再讲原理

## Key Concepts
- **象数疗法**：以数字组合调治疾病的方法，全称八卦象数疗法
- **先天八卦数**：乾一兑二离三震四巽五坎六艮七坤八
- **后天八卦象**：实际应用取象的体系，先天为体后天为用
- **头心胃**：连接潜意识的三处，用作象数适配校验点

## Mental Models
- Use 头心胃校验 when 念象数方不适——换方，不硬扛
- Think of 先天数+后天象 as 体用配合——数是体、象是用
- Use 先教使用原则 when 教任何复杂技能——先上手再究理

## Anti-patterns
- **念方一成不变**：念着不舒服要换，头心胃是校验信号
- **先啃完理论再上手**：作者实用主义：先用起来，好奇再回头研究原理

## Worked Example
作者用『学手机』比喻教学顺序：先教拨号打电话（用法），再究电磁感应（原理）。象数疗法即取先天八卦之数、后天八卦之象；琪儿问『念着不舒服』指什么，答：头、心、胃三处的不适，它们连接潜意识。这组数字是否适合你，身体会告诉你。

## Key Takeaways
1. 象数疗法=先天数+后天象，用数字组合调治
2. 念方是否适合自己，以头心胃的不适感校验
3. 教学与实践遵循『先用后理』的实用主义
4. 先天为体后天为用是象数体系的理论支点
